# Hytale Mod: Slime NPC + Drop Table (Custom Loot Tables)

Companion mod for the [Hytale Modding Manual](https://hytale-moddings.github.io/hytale-modding-docs/) tutorial on **Custom Loot Tables**.

**Repository:** [hytale-moddings/hytale-mods-custom-loot-tables](https://github.com/hytale-moddings/hytale-mods-custom-loot-tables)

## What This Mod Does

Extends the [Slime NPC mod](https://github.com/hytale-moddings/hytale-mods-custom-npc) with a custom **drop table** — defines what items the slime drops when killed, with weighted probabilities.

This is **CreateACustomNPC v1.1.0** — the same mod identifier as the base NPC but with `Drop_Slime.json` added. Use this version *or* the base — not both.

## Installation

1. Copy the mod folder to `%APPDATA%/Hytale/UserData/Mods/CreateACustomNPC/`
2. The folder name **must** be `CreateACustomNPC`
3. Start a Hytale server with the mod enabled

## Drop Table Highlights

- Weighted random drops on slime death
- Demonstrates `Drop` schema with `Items`, `Weight`, `Min`/`Max` count
